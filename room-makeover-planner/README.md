# Our Wentworth Diaries — Room Makeover Planner

A mobile-first, static visual prototype using the supplied research package. It has no backend, accounts, APIs, shopping catalogue, or AI logic.

## Run locally

From this directory:

```sh
python3 -m http.server 4173 --directory dist
```

Open `http://localhost:4173/`.

## Content and sourcing

- `dist/data.js` holds curated room plans and structured source records. Goal and project level select and prioritise fixed action records; plan content is deterministic.
- Source records separate `exact` documented claims from `look` style inspiration. A `documented` verification status means supported by the supplied research, not approved by Helen.
- Original Instagram posts are the evidence links. Retailer and affiliate URL fields are intentionally empty until verified.
- Historic costs retain their original scope and are not estimates for a visitor's project.
- The checklist and saved plan use browser local storage on the current device.
- `screenshots/` contains three stitched mobile browser captures for comparing the plan opening, practical actions and checklist.
